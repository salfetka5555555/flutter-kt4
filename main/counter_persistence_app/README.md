# counter_persistence_app

Отдельное Flutter-приложение: счётчик нажатий, который сохраняет значение между запусками.

## Как это работает

- При открытии экрана приложение читает `button_press_count` из локального хранилища.
- Если сохранённого значения ещё нет, используется `0`.
- При нажатии кнопки значение увеличивается на единицу и записывается через `SharedPreferences`.
- После закрытия и повторного запуска приложение загружает последнее сохранённое значение.

Для хранения используется пакет `shared_preferences`. Данные сохраняются локально на устройстве и не требуют сервера или подключения к интернету.

## Запуск на macOS

Убедитесь, что Flutter установлен:

```bash
flutter doctor
```

Перейдите в папку проекта:

```bash
cd counter_persistence_app
```

Сгенерируйте платформенные папки (Android, iOS, macOS и другие):

```bash
flutter create --project-name counter_persistence_app .
```

Получите зависимости:

```bash
flutter pub get
```

Запустите приложение:

```bash
flutter run
```

Чтобы проверить сохранение, несколько раз нажмите кнопку, полностью закройте приложение и запустите его снова. Счётчик должен показать прежнее значение.

## Основные файлы

- `lib/main.dart` — интерфейс, загрузка, увеличение и сохранение счётчика.
- `pubspec.yaml` — зависимость `shared_preferences`.
